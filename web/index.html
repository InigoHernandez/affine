      05

      How it was made

      A break chopper's fork, a sound chip rebuilt from its public documents.

      1. 01ForkedFrom LOAF BREAKER by FLEXOR, itself CHOPPAH's fork by Laurens Profittlich: the slicer, the keys, the patterns.
      2. 02Clean roomThe chip's effects written from psx-spx's public description: only its documented numbers, each credited. No ROM, no SDK, no emulator code.
      3. 03Checked183 engine checks and 38 for the chip, every build; 100 scripted sessions in the simulator.
      4. 04ShakenRandom hands on every control for 15 minutes, three times; memory checkers on every run. Three bugs found and fixed.
